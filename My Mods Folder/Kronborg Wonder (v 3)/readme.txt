Thanks for downloading the Kronborg Wonder, by me (Pouakai) and sukritact, with help from many others! 

In order to change the splash screen, follow the below steps:

1. Open the Art folder within this mod

2. Locate the file named 'Kronborg_splash.dds'

3. Right click on this file, and click 'rename'

4. Rename the file to anything, but keep in mind there must always be a file named 'Kronborg_Splash.dds' in order for the
   mod to work.

5. Locate the file named 'Kronborg_splash_a.dds'

6. Right click on this file, and click rename

7. Rename to 'Kronborg_splash.dds'

8. Load the game. Remember, there must always be 'Kronborg_splash.dds' in order for this file to work!!

NOTE: If you are using Whoward's Multiple Wonder Splashes mod, there MUST be a file named 'Kronborg_splash.dds' and one named 'Kronborg_Splash_a.dds'
